# Sweepr Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build Sweepr v0.1.0, a native Windows updater that lists outdated packages from WinGet, Chocolatey and Scoop and updates them with at most one UAC prompt.

**Architecture:** Cargo workspace. `sweepr-core` is a UI-free lib (model, parsers, adapters, orchestrator, rules, settings, job/elevation). `sweepr` is the bin: Win32 GUI plus CLI flags in one exe. Threads and channels, no async runtime.

**Tech Stack:** Rust (stable, MSVC target, `crt-static`), `windows-sys`, `serde`, `serde_json`. No other deps.

**Spec:** `docs/superpowers/specs/2026-11-08-sweepr-design.md`

## Global Constraints

- Rust, static CRT (`+crt-static`), zero web runtimes, no .NET, no Electron.
- Deps limited to `windows-sys`, `serde`, `serde_json`. No `toml`, no `regex`.
- Sweepr makes zero network calls and sends no telemetry.
- Manager commands are spawned as argument vectors, never through a shell.
- Package IDs must match `A-Z a-z 0-9 . _ + -`, length 1..=128.
- Discovery timeout default 60 s, configurable. Cancel effective < 50 ms.
- Idle CPU ~0%, idle working set < 15 MB, no polling timers, first render < 50 ms.
- No main-window scrollbar. List is `LVS_OWNERDATA`, 28 px rows, row and column gridlines.
- One crimson primary control per region (`#D02946`, white label). Text accompanies every color.
- Settings: JSON, versioned, atomic write (temp, `FlushFileBuffers`, `ReplaceFileW`), corrupt file quarantined.
- Portable build writes only to `data\` beside the exe (`portable.flag`); installed uses `%LOCALAPPDATA%\Sweepr`.
- Min OS Windows 10 1809. Every support claim without a real run is labelled Unverified.
- Error codes: `SWP-101 manager-missing`, `102 timeout`, `103 parse-failed`, `201 uac-declined`, `202 elevated-pipe-lost`, `203 job-rejected`, `301 settings-corrupt`, `401 installer-failed`.
- Gate before every commit: `cargo fmt --check`, `cargo clippy --all-targets -- -D warnings`, `cargo test --locked`.
- Commit trailer on every commit: `Co-Authored-By: Claude Sonnet 5.5 <noreply@anthropic.com>` and `Claude-Session: https://claude.ai/code/session_016hSe4cP5AtwpCcz49F4dWM`.
- Hand-written fixtures are labelled `synthetic` in the file name and AUDIT; real captures replace them (Task 3).

## Review Focus

1. WinGet prints spinner/progress lines (`-`, `\`, `|`, `/`, block bars) and versions like `Unknown` or `< 1.2`; parser must skip noise and keep the row. Tested in Task 3.
2. Wide (CJK/emoji) characters break byte-offset columns in the WinGet table; offsets must be by display cells. Tested in Task 3.
3. "Everything up to date" and empty output from any manager gives an empty list, not an error. Tested in Task 3.
4. `settings.json` written by a newer version is not overwritten; saved window position on a removed monitor is clamped on-screen. Tested in Task 4.
5. A hostile package ID in a job file (`foo & calc`, `..\x`, 500 chars) is rejected and nothing runs; a hung manager's child processes die on timeout/cancel. Tested in Tasks 2, 5, 8.
